Enterprise Integration Atlas

A reference atlas for the enterprise systems FDE-DEs meet on every deployment — ERPs, procurement suites, CLMs, warehouses, BI tools, identity providers, document sources, observability. For each: what it does, how to integrate, auth patterns, API shapes, code snippets, the political layer behind it.

How to use this

Not designed to be read end-to-end. Use it as a reference — when a customer says "we use SAP ECC + Coupa + Snowflake + Tableau + Okta," skim those five chapters before the discovery call. Each entry has the same shape: what it is, how to integrate, auth, code, gotchas, escalation routes when the customer's IT team gates access.
