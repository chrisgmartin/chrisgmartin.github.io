Section A · Orient
00 Start Here Master index, study schedule, the reframe that separates "ML researcher" from "full-stack DS who ships." 01 The Roles Decoded Staff Data Scientist (fraud / identity) and Data Scientist (multimodal sensor AI), side by side. What each team actually does, what the stack means, what the loop is really testing. 02 Positioning From Scratch Mindset before content — how to interview honestly when you've done some production ML but not at staff scale, and how to lean on adjacent experience without overclaiming.
Section B · Core Data Science
03 ML Fundamentals Supervised models for tabular data — logistic regression, gradient boosting, calibration, evaluation under skew, model selection at staff bar. Critical 04 Feature Engineering "Inventive feature engineering" demystified. Entity-level features, leakage avoidance, drift, feature stores, and the hard part: features that encode domain insight. Critical 05 Fraud & Imbalanced Data Class imbalance, cost-sensitive learning, precision-recall tradeoffs, threshold tuning at real-world fraud rates, evaluation when labels are scarce or delayed. Fraud-domain-flavored. Critical 06 Prompt Engineering, Applied N-shot examples, prompt templates, lens/parameter configuration, prompt-as-config patterns, iterating prompts against an eval set. Solutions-Engineering-flavored. 07 Time-Series & Signals Signal processing basics, time-series features, sensor data prep, alignment and resampling, video and multimodal data prep. The "raw data to testable results" workflow. 08 Data Pipelines, Applied Data acquisition, labeling workflows (Encord and others), iterative preprocessing cycles, feature pipelines, training data versioning, the loop from raw asset to model-ready dataset. 09 Production ML Writing production code & tests, real-time inference, monitoring, retraining cadence, A/B rollouts for models, on-call considerations. The Staff-DS "end-to-end ownership" bar. Critical
Section C · Coding
10 Coding Fundamentals Python patterns full-stack DS interviewers reach for — clean classes, generators, testability, vectorization vs explicit loops, useful Big-O intuition. 11 Coding Problems Drillable problems — feature engineering puzzles, imbalanced-data evaluation, ranking and aggregation, a couple of classic algos. Multiple approaches per problem; drill mode hides solutions. Drill mode
Section D · Production / Cloud
12 AWS Data Stack EC2, S3, RDS, Redshift, plus PostgreSQL as the system of record. What the standard fraud-stack implies about how their work is structured, and how to discuss it credibly. 13 MLOps Applied CI/CD for models, experiment tracking, shadow deploys, canary rollouts, drift monitoring, retraining triggers — the operational glue that separates a Jupyter result from a product.
