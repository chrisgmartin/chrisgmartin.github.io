dbt Agent Skills

dbt Labs' curated skills for analytics engineering, the Semantic Layer, dbt Mesh, platform operations and one-off migrations — installable as a Claude Code plugin.

by dbt Labsrepo github.com/dbt-labs/dbt-agent-skillslicense Apache-2.0skills 15checked September 2026

What it is

The official collection from dbt Labs. Skills are not slash commands: once installed, the agent loads the relevant one when your prompt matches — build or modify models, add unit tests, backfill documentation, define metrics with MetricFlow, judge whether a change breaks downstream consumers, diagnose failed platform jobs, or run a migration.

Install

Claude Code (plugin)

Add the marketplace, then install the analytics-engineering skills; add the migration plugin only when you need it.

Claude Code
/plugin marketplace add dbt-labs/dbt-agent-skills
/plugin install dbt@dbt-agent-marketplace
/plugin install dbt-migration@dbt-agent-marketplace

Other agents (Vercel Skills CLI)

Works with Cursor, Cline, Copilot and 30+ agents.

shell
npx skills add dbt-labs/dbt-agent-skills            # all
npx skills add dbt-labs/dbt-agent-skills/skills/dbt  # analytics engineering only
npx skills add dbt-labs/dbt-agent-skills --skill using-dbt-for-analytics-engineering

Tessl

A package manager for agent skills.

shell
tessl install dbt-labs/dbt-agent-skills

Notes

  • Most skills assume a working dbt project and, for platform skills, access to the dbt MCP server or Admin API.
  • The repo ships an evals/ harness and a repo validator, and publishes both Claude Code and Cursor marketplaces.

Descriptions above are paraphrased from each skill's SKILL.md frontmatter as of September 2026; the repo is the source of truth and moves faster than this page.
