Data Engineering Skills

Eight expert skills for the modern lakehouse and streaming stack — Iceberg, Paimon, Fluss, Flink, Iggy, Lance, Firn and Docker Compose.

by Gordon Murrayrepo github.com/gordonmurray/data-engineering-skillslicense MITskills 8checked September 2026

What it is

Independent, single-file skills that make Claude an operator for specific data technologies: open table formats, stream processing, streaming storage, ML-native formats and local orchestration. Each SKILL.md is written as an operating guide — inspect first, safety rails, verify, update checklist — rather than a reference article.

Install

Claude Code

Copy or symlink a skill folder into ~/.claude/skills/ (global) or .claude/skills/ (per project). Claude Code discovers the SKILL.md automatically and loads it when your prompt matches its description.

shell
git clone https://github.com/gordonmurray/data-engineering-skills
ln -s "$PWD/data-engineering-skills/iceberg" ~/.claude/skills/iceberg

Reference a skill directly

Point at the file in a conversation.

Claude Code
@iceberg/SKILL.md help me migrate an Iceberg v2 table to v3 deletion vectors

Claude.ai

Zip a skill folder and upload it under Settings → Capabilities → Skills.

Claude API

Pass the skill via container.skills on the Messages API (Code Execution Tool beta).
