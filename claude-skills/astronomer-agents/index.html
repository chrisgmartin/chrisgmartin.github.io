Astronomer Agents — Airflow skills

Thirty-four Airflow skills plus an Airflow MCP server and the af CLI — authoring, testing, debugging, deploying, lineage, migrations, language SDKs and warehouse analysis.

by Astronomerrepo github.com/astronomer/agentslicense Apache-2.0skills 34checked September 2026

What it is

Astronomer's agent tooling for data-engineering workflows, Apache 2.0 and compatible with open-source Airflow (2.x and 3.x). The Claude Code plugin bundles the MCP server, the skills and session hooks; the skills themselves are tool-agnostic and install into 25+ agents via skills.sh.

Install

Claude Code (plugin, recommended)

Includes the Airflow MCP server (runs via uvx from PyPI) and the skills.

shell
claude plugin marketplace add astronomer/agents
claude plugin install astronomer-data@astronomer

Any agent (skills only)

Installs all skills into your project; omit --skill '*' to pick individually.

shell
npx skills add astronomer/agents --skill '*'

Open-source Airflow

The MCP server works with any Airflow 2.x/3.x REST API — set AIRFLOW_API_URL to your instance.

shell
export AIRFLOW_API_URL=http://localhost:8080
