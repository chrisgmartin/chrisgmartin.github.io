What a skill is

An Agent Skill is a folder with a SKILL.md: YAML frontmatter (name, description) that is always loaded so the agent knows when the skill applies, and a Markdown body — plus optional references/, scripts/ and assets/ — loaded only when a prompt matches. Skills are not slash commands; you describe the job in plain language and the agent pulls in the expertise. In Claude Code they live in ~/.claude/skills/ or a project's .claude/skills/, or arrive as plugins from a marketplace.
